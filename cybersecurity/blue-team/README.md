# blue-team-cyberchallenge
Blue team cybersecurity capstone project involving Windows hardening, SIEM monitoring, firewall configuration, and threat detection using Wazuh and Security Onion.

## Overview
This project involved securing an enterprise-style network environment as part of a blue team cybersecurity challenge. Responsibilities included Windows system hardening, CIS benchmark remediation, SIEM monitoring, firewall configuration, account management, and threat detection.

## Objectives
- Harden Windows systems using CIS recommendations
- Monitor and analyze security alerts
- Identify suspicious network activity
- Improve network security posture
- Configure defensive controls
- Respond to potential threats

## Technologies Used
- Wazuh
- Security Onion
- Snort
- Windows Server 2022
- Windows Server 2016
- Nmap
- Active Directory
- DFS Management
- Windows Firewall

## Responsibilities
- Implemented CIS benchmark recommendations
- Enabled and configured Windows Firewall profiles
- Managed and secured user accounts
- Installed security updates
- Assisted with centralized file management setup
- Monitored SIEM and IDS alerts
- Configured automatic blocking for malicious hosts

## Security Events Identified
- Command injection attempts
- Webroot directory traversal
- Possible brute force attacks
- Worm/exploit activity

## Skills Demonstrated
- Blue team operations
- Windows hardening
- SIEM monitoring
- Threat detection
- Security analysis
- Firewall administration
- Network defense
- Incident response concepts
